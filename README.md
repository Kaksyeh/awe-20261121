A tiny program that writes one short relaxing text to `entry.txt`: a lighthouse turning under stars whose light set out before anyone alive had a name for it, only now reaching us. The text is fixed and carried inside the program, so every run produces the exact same output.

## Run it

```sh
node main.ts
```

This writes the text to `/output/entry.txt`. To write it somewhere else, set `MAKEFUN_OUTPUT_DIR` first:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
